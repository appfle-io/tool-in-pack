# TIP — TOOL-IN-PACK

**작은 도구들을 한곳에 모은 오프라인 유틸리티 앱.**
PDF·이미지·PDF 병합·모자이크·QR·동영상 GIF부터 JSON·정규식·색 대비·앱 아이콘·이미지 글자 추출(OCR), 파일 압축·영상 모자이크·마크다운·단위 변환·환율 계산까지,
파일을 서버로 보내지 않고 브라우저(기기) 안에서만 처리하고, **제비뽑기 · 사다리타기 · 선착순 골인** 같은 미니게임도 함께 들어 있습니다.
Mac 앱에서는 **클립보드 히스토리 · 노치 아일랜드 · Spotlight 형 전역 검색 · 스티커 메모 · 화면 스포이드 · 스크린샷 표시 · 창 분할**까지 함께 씁니다.
한국 주소(도로명·지번·영문·우편번호)와 해외 주소 검색, **해외직구용 영문 주소 변환**도 한 화면에서 되고, 저장해 둔 **송장번호로 배송 조회**도 바로 엽니다.

- **라이브**: <https://appfle-io.github.io/tool-in-pack/>
- 설치 없이 웹으로 열고, 홈 화면에 추가하면 앱처럼 전체 화면으로 쓸 수 있습니다.
- 한 번 열어 두면 **인터넷 없이도** 동작합니다(오프라인 캐시).

## 1. 시작하기

### iPhone / iPad (Safari)

1. Safari에서 <https://appfle-io.github.io/tool-in-pack/> 를 엽니다.
2. 하단 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면의 **TIP** 아이콘으로 실행하면 주소창 없이 전체 화면으로 뜹니다.

### 데스크톱 / Mac

1. Chrome · Edge · Arc · Safari 에서 위 주소를 엽니다.
2. 주소창 오른쪽의 **설치** 아이콘(또는 메뉴 → 앱 설치 / 홈 화면에 추가)으로 설치하면 독·Dock에서 바로 실행됩니다.
3. 넓은 화면에서는 두 칸 레이아웃으로 바뀌고, 파일을 **끌어다 놓기**로 바로 열 수 있습니다.

### Mac 앱 — 노치(반원·전체 보기) · 빠른 실행 검색

Mac에는 **메뉴 막대에 상주하는 앱**으로 설치할 수 있습니다. 웹(PWA)과 같은 화면을 그대로 쓰고, **홈 화면 아이콘과 같은 초록색 TIP 아이콘**을 누르면 화면 위 가운데에 **노치**가 열립니다(v1.17.0 — 예전 반원 퀵바 창은 노치 안의 **간단히 보기**가 되었습니다).

1. [Releases — v1.15.0](https://github.com/appfle-io/tool-in-pack/releases/tag/v1.15.0) 에서 `TIP_1.15.0_universal.dmg` 를 내려받습니다(Apple Silicon · Intel 공용). Developer ID 서명·공증된 빌드라 첫 실행 경고가 없습니다.
2. DMG를 열고 **TIP** 을 **응용 프로그램** 폴더로 끌어다 놓습니다.
3. 업데이트는 **⚙️ → 앱 업데이트 → 업데이트 확인** 으로 받습니다. 다운로드 폴더에서 바로 실행하지 말고 **응용 프로그램 폴더에 둔 앱**에서 업데이트해야 합니다.

- 새 버전이 나오면 **⚙️ → 앱 업데이트 → 업데이트 확인** 으로 받습니다. 진행률 로딩바가 나오고, 설치가 끝나면 앱이 저결로 다시 시작됩니다. 창을 열어 둔 상태에서도 업데이트할 수 있습니다.
- 메뉴 막대 아이콘을 숨기고 싶으면 **⚙️ → 메뉴 막대에 표시** 를 끄면 됩니다(Dock 아이콘은 그대로 남습니다).
- 창의 **X** 를 눌러도 앱은 꺼지지 않고 숨겨집니다. Dock 아이콘이나 메뉴 막대에서 다시 열 수 있고, 완전히 끄려면 메뉴 막대 메뉴의 **TIP 종료**를 씁니다.
- 웹과 Mac 앱은 **같은 저장소(localStorage)** 를 씁니다 — 모듈 켜기/끄기, 모듈 순서, 화면 모드, 색상이 두 곳에서 똑같이 유지됩니다.

### 홈 화면(모듈 목록)

모듈은 성격에 따라 **문서·글 · 사진·영상 · 파일 · 계산·조회 · 개발·디자인 · 게임 · Mac 화면 도구** 일곱 묶음으로 나뉘어 있습니다(v1.19.0).

- 맨 위 **고정됨**: 핀을 켠 모듈만 모입니다. 하나도 없으면 이 칸은 나타나지 않습니다.
- 그 아래 **문서·글 → 사진·영상 → 파일 → 계산·조회 → 개발·디자인 → 게임 → Mac 화면 도구** 순서로 모듈이 놓입니다.
- 묶음 제목 옆 숫자는 그 묶음에 든 모듈 수입니다.
- 카드를 누르면(오른쪽 **>** 도 같음) 모듈이 열립니다 — 홈 카드는 기본적으로 **누르면 실행** 하나만 있습니다(v1.15.3).
- 오른쪽 위 **편집** 을 누르면 편집 모드가 되고, 그때만 카드마다 **순서 핸들(⋮⋮) · 핀 · 켜기/끄기 스위치** 가 나타납니다. 편집 모드의 버튼은 터치 영역 **44×44px** 이상입니다. **완료** 를 누르면 다시 실행만 남습니다.
- **스위치**로 모듈을 켜고 끕니다(끈 모듈은 실행되지 않음). **핀** 을 누르면 **고정됨** 칸으로 올라가고, 다시 누르면 원래 묶음으로 돌아갑니다.
- 좁은 화면은 한 줄씩, 넓은 화면(900px 이상)은 묶음마다 두 줄로 보입니다.
- **드래그로 순서 바꾸기**: 카드 왼쪽의 점 6개(**⋮⋮**) 핸들을 잡고 위아래(넓은 화면은 사방)로 끌면 **같은 묶음 안에서만** 순서가 바뀝니다. 끄는 동안 원래 자리에는 점선 틀이 남고, 손을 때면 순서가 저장되어 **새로고침·앱을 다시 열어도**, 스위치로 껐다 켜도 그 순서가 유지됩니다. 다른 묶음으로는 넘어가지 않습니다(고정은 핀으로).
- **키보드로 순서 바꾸기**: 핸들에 초점을 두고 **↑ ↓**(넓은 화면은 **← →**도)를 누르면 한 칸씩 옮겨지고, 옮긴 자리를 토스트로 알려 줍니다.
- **꺼진 모듈**: 스위치를 끈 모듈은 원래 묶음에서 빠져 맨 아래 **꺼진 모듈** 한 곳에 모입니다. 꺼진 모듈이 없으면 이 칸은 나타나지 않습니다. 다시 켜면 원래 묶음으로 돌아가고, 고정해 두었던 모듈은 **고정됨**으로 돌아갑니다.

## 2. 모듈별 사용법

### 1) 문서 리더 — PDF, HWP, HWPX

- **파일 열기** 버튼을 누르거나 파일을 화면에 끌어다 놓습니다. (PDF · HWP · HWPX)
- **PDF**: 페이지 이동(‹ ›), 확대/축소, 폭 맞춤, 회전. 모바일에서는 두 손가락 핀치로 확대할 수 있습니다.
- **HWP / HWPX**: 문서를 스크롤해 읽습니다. 표·이미지도 함께 표시됩니다.
- 페이지 수가 많은 PDF도 기기 안에서 그때그때 그려서 보여줍니다(파일 업로드 없음).
> 암호가 걸린 문서는 열리지 않을 수 있습니다. 암호를 푼 파일로 다시 시도해 주세요.

### 2) 이미지 컨버터 — 포맷 변환과 크기 조절

- **이미지 선택**(여러 장 동시 선택 가능) 또는 끌어다 놓기.
- **입력**: JPG · PNG · WebP · GIF · BMP · SVG · AVIF · ICO · HEIC/HEIF
- **출력**: PNG · JPG · WebP · ICO · BMP · PDF
- 옵션: **품질**(JPG/WebP), **너비**(px, 비율 유지) — 비워 두면 원본 크기.
- **변환** 후 파일별 `원본 → 결과` 용량과 증감률을 보여 줍니다. **저장** 또는 **전체 저장**으로 내려받습니다.
- 여러 장을 한 번에 변환할 때 파일명이 겹치면 `-2`, `-3`이 붙습니다.
> HEIC는 브라우저가 직접 못 읽으면 내장 디코더로 변환합니다. 아주 큰 HEIC는 시간이 조금 걸릴 수 있습니다.
> iPhone Safari는 WebP **저장**을 지원하지 않아 PNG로 대체되는 경우가 있습니다(화면에 안내 표시).

### 3) PDF 합치기 — 병합과 페이지 추출

상단에서 **합치기 / 페이지 추출** 두 가지 모드를 고릅니다.

**합치기**
1. **PDF 선택**으로 2개 이상 올립니다(끌어다 놓기 가능). 파일마다 페이지 수와 용량이 표시됩니다.
2. 행 오른쪽 **∧ ∨** 로 순서를 바꾸고, **✕** 로 목록에서 뺍니다.
3. **합치기** → 결과 카드에 `전체 페이지 수 · 용량`이 나오면 **저장**.

**페이지 추출**
1. PDF 1개를 올리면 **총 페이지 수**가 표시됩니다.
2. **범위** 칸에 `1, 3-5` 처럼 입력하거나, 아래 **페이지 번호 칩**을 눌러 고릅니다. (칩과 입력은 서로 맞춰 바뀝니다)
3. **선택 페이지 추출** → `n페이지` 결과를 **저장**.

> 범위 표기: `3` (한 장), `2-6` (구간), `1, 4, 7-9` (섞어 쓰기). 문서 범위를 벗어난 번호는 무시됩니다.
> 암호가 걸린 PDF는 결과가 빈 페이지로 나올 수 있습니다.

### 4) 사진 모자이크 — 사진 가리기와 촬영 정보 지우기

사진을 올리면 **먼저 사진에 들어 있는 정보를 보여 줍니다** — 촬영 기기, 촬영 일시, 조리개·ISO·렌즈, 그리고 **GPS 위도·경도**(있으면 붉게 표시). 정보가 없으면 "EXIF / 위치정보 없음"이라고 나옵니다.

1. **사진 선택** 또는 끌어다 놓기 (JPG · PNG · WebP · HEIC)
2. **가리기 도구**
   - **방식**: 모자이크 / 블러
   - **모양**: 붓(문지르듯 칠하기) / 사각(끌어서 영역 지정)
   - **강도**: 1~10 (모자이크 블록 크기·블러 반경)
   - **붓 크기**: 화면에서 보이는 크기 그대로
   - **실행 취소**로 한 번에 하나씩 되돌리고, **초기화**로 원본으로 돌립니다.
3. **저장**: PNG(무손실) 또는 JPG → 저장하면 **저장한 파일을 다시 검사해서** `저장 전 EXIF n항목 · GPS 포함 → 저장 후 0항목`과 “메타데이터 0건”을 확인해 보여 줍니다.

> 사진을 캔버스로 다시 그려 저장하기 때문에 EXIF·GPS·촬영 정보가 **완전히 사라집니다**. (원본 파일은 그대로 남아 있습니다)
> 사진이 아주 크면 긴 변 3200px로 맞춰 편집합니다.

### 5) QR 생성기 — URL, 텍스트, 와이파이

1. 위쪽에서 **URL / 텍스트 / 와이파이** 중 하나를 고릅니다.
   - URL: 주소를 입력
   - 텍스트: 여러 줄 문장도 가능
   - 와이파이: **SSID**, **비밀번호**, **암호화**(WPA/WPA2/WPA3 · WEP · 없음) — 손님이 QR만 찍으면 와이파이에 접속됩니다.
2. 입력하는 즉시 **미리보기**가 갱신되고, QR에 담기는 실제 내용도 아래에 표시됩니다.
3. 옵션: **크기**(256 / 512 / 1024px) · **여백**(0~8) · **오류 정정**(L/M/Q/H) · **전경/배경색**(색 바꾸기 버튼 포함)
4. **PNG 저장** 또는 **SVG 저장**(인쇄·확대용).

> 비밀번호에 `;` `,` `:` `"` `\` 가 들어가도 자동으로 이스케이프되어 스캔이 깨지지 않습니다.
> 너무 긴 내용은 QR로 만들 수 없어 안내가 뜹니다.

### 6) 동영상 자르기 — GIF나 짧은 클립으로

동영상을 올리면 길이·해상도·용량이 표시되고, 위쪽 플레이어에서 미리 볼 수 있습니다.

- **구간**: 시작/끝 슬라이더로 자를 구간을 정합니다. 아래에 `구간 길이 · GIF 프레임 수`가 나옵니다.
- **GIF 변환**: FPS(5/10/15)와 가로 폭(320/480/640)을 고르고 **GIF 만들기** → 진행률이 표시되고, 완성되면 미리보기와 함께 `프레임 수 · fps · 용량`이 나옵니다 → **저장**.
- **동영상 자르기**: **클립 자르기** → 구간 길이만큼 실시간으로 다시 인코딩한 뒤 `MP4`(Safari) 또는 `WebM`(Chrome/Edge) 클립을 만들어 줍니다. 소리가 있으면 함께 담깁니다 → **저장**.

> **iOS Safari에서는 30초 이내의 짧은 클립**에서 가장 안정적입니다.
> GIF는 최대 300프레임까지 만들 수 있습니다(구간을 줄이거나 FPS를 낮추세요).
> 모든 처리는 기기 안에서 하며, 파일은 어디로도 전송되지 않습니다.


### 7) 개발자 툴팩 — JSON, Base64, JWT, 시각, UUID

위쪽 탭으로 도구를 바꿉니다. 다섯 가지 모두 기기 안에서만 계산합니다.

- **JSON**: 입력 칸에 JSON을 붙여 넣고 **정렬 2칸 / 정렬 4칸 / 압축**을 누르면 아래 **결과** 칸에 나옵니다. **검증**은 결과를 바꾸지 않고 `유효한 JSON — 객체 · 키 12개 · 1.2 KB`처럼 종류와 크기만 알려 줍니다. 문법이 틀리면 오류 메시지와 위치(줄·글자)를 보여 줍니다. **결과 복사**로 결과를 클립보드에 담습니다.
- **Base64 · URL**: UTF-8 기준이라 한글·이모지도 깨지지 않습니다. **Base64 인코딩 / 디코딩**, **URL 인코딩 / 디코딩** 네 버튼. **결과를 입력으로**를 누르면 결과가 입력 칸으로 옮겨져 이어서 변환할 수 있습니다.
- **JWT**: 토큰을 붙여 넣으면 **Header · Payload를 자동으로 디코드**해 각각 복사할 수 있게 보여 줍니다. `iat` `nbf` `exp`는 **한국 시간(KST)** 으로 바꿔 표시하고, `exp`는 남은 시간 또는 만료 여부까지 적습니다. **서명(Signature)은 검증하지 않습니다** — 값 확인용입니다.
- **타임스탬프**: Unix 값(10자리 초 / 13자리 밀리초)을 넣고 **변환**하면 **한국 시간 · ISO 8601 · Unix 초 · Unix 밀리초**를 한 번에 보여 줍니다. **현재 시각** 버튼으로 지금 값을 채웁니다. 아래 칸에서 날짜·시각을 고르면 **한국 시간 기준**으로 Unix 초를 계산합니다.
- **UUID**: **1개 / 5개 / 10개 생성** → **UUID v4**가 만들어지고 **복사**로 전체를 복사합니다.

> JSON 오류 위치는 브라우저가 알려 주는 범위 안에서 표시합니다(최신 브라우저는 문제 구간만 알려 주기도 합니다).
> JWT는 디코드만 하므로 서명이 맞는지는 확인할 수 없습니다.

### 8) 텍스트 비교 — 줄 단위 비교와 글자수

위 탭에서 **비교**와 **정리 · 통계**를 오갑니다.

- **비교**: **원본**과 **수정본**을 넣으면 입력하는 동안 자동으로 비교합니다. 줄 단위로 **추가(초록 +) / 삭제(빨강 −) / 동일**을 나란히 번호와 함께 보여 주고, 위에 `추가 2줄 · 삭제 1줄 · 동일 3줄` 통계가 나옵니다. **좌우 바꾸기**로 두 칸을 맞바꿉니다.
- **정리 · 통계**: 붙여 넣는 즉시 **글자수(공백 포함·제외) · 단어 수 · 줄 수 · UTF-8 바이트**를 셉니다.
  - **앞뒤 공백 정리**, **빈 줄 제거**, **중복 줄 제거**, **오름차순 정렬**, **내림차순 정렬**, **되돌리기**, **복사**.
  - **되돌리기**는 바로 전 상태로 한 번 돌아갑니다.

> 줄이 1,200줄을 넘는 큰 입력은 계산을 가볍게 하려고 자리 기준으로 비교하며, 그 사실을 화면에 표시합니다.
> 중복 줄 제거는 앞뒤 공백을 무시하고 같은 줄을 하나만 남깁니다.

### 9) 정규식 테스터 — 일치 표시와 캡처 그룹

1. **패턴** 칸에 정규식을 넣고 오른쪽 **g i m s** 플래그를 켜고 끕니다.
2. **테스트 문자열**에 글을 넣으면 일치하는 부분이 **바로 강조**되고, 아래에 `매치 3개`가 표시됩니다.
3. **매치 목록**에서 각 매치의 값과 위치(`4–20`), **캡처 그룹**(이름이 있으면 이름까지)을 확인합니다.
4. **프리셋 칩**(이메일 · 휴대폰 · URL · IPv4 · 한글만 · 숫자만)을 누르면 패턴이 채워집니다.

> 패턴이 잘못되면(예: `[`) 앱이 멈추지 않고 **문법 오류 메시지**만 보여 줍니다.
> `g`를 끄면 첫 매치만 강조하고, 전체 매치 수는 참고로 함께 알려 줍니다.
> 자바스크립트 정규식 문법을 그대로 씁니다(다른 언어의 정규식과 일부 문법이 다릅니다).

### 10) 색상 대비 체크 — 색 코드 변환과 WCAG 대비

1. **글자색**과 **배경색**을 색 상자에서 고르거나, **HEX · RGB · HSL** 칸에 직접 입력합니다. 한 칸을 고치면 나머지 두 칸이 즉시 함께 바뀝니다.
   - HEX `#2E5E4E`, RGB `46, 94, 78`, HSL `162, 32%, 27%` 형식.
2. 아래 **대비율**이 `7.43 : 1`처럼 나오고, **일반 텍스트 AA(4.5:1) · AAA(7:1) · 큰 텍스트 AA(3:1)** 통과 여부를 배지로 보여 줍니다.
3. **미리보기**에서 24px 큰 텍스트와 14px 본문이 실제 색으로 어떻게 보이는지 확인합니다.
4. **글자 ↔ 배경** 버튼으로 두 색을 맞바꾸고, 각 칸 옆 **복사**로 값을 복사합니다.

> **스포이드** 버튼은 화면의 색을 집을 수 있는 브라우저(Chrome·Edge 등)에서만 나타납니다. iPhone Safari에는 없습니다.

### 11) 앱 아이콘 생성기 — PNG 7종 + manifest

1. **이미지 선택** 또는 끌어다 놓기 (PNG · JPG · WebP · SVG). 1024px 이상을 권장합니다.
2. **맞춤** 방식 선택
   - **정사각 크롭**: 가운데를 기준으로 꽉 채워 자릅니다(로고가 중앙에 있을 때).
   - **여백 맞춤**: 이미지 전체가 들어가게 하고 남는 곳을 **배경색**으로 채웁니다.
3. **PNG 7종 만들기** → **16 · 32 · 48 · 180 · 192 · 512 · 1024px** 미리보기와 각 파일 용량이 나옵니다. 미리보기를 누르면 그 크기 하나만 저장됩니다.
4. **ZIP 저장** → `app-icons.zip`에 `icons/icon-*.png` 7개와 **`manifest-snippet.json`** 이 함께 담깁니다. ZIP을 프로젝트에 풀고 스니펫을 `manifest.json`의 `icons`에 넣으면 됩니다.

> 1024px보다 작은 원본은 512 · 1024px를 확대하므로 조금 흐려질 수 있습니다.
> 결과는 투명 배경을 살린 PNG입니다(원본이 JPG면 사각형 배경이 그대로 남습니다).

### 12) 글자 추출 — 화면이나 이미지에서 글자만

위쪽에서 가져올 곳을 고릅니다.

- **화면에서** (Mac) — **화면 영역 드래그해서 찍기**를 누르고 화면을 끌면 그 영역만 찍혀 바로 읽습니다. 처음 한 번은 macOS **화면 기록** 권한을 물어봅니다. 예전 '화면 글자 읽기' 단축키(설정 → 모듈 → 글자 추출)와 `#/drag-ocr` 주소도 이 화면으로 옵니다.
- **이미지에서** (웹·Mac) — **이미지 선택** 또는 끌어다 놓기 (PNG · JPG · WebP · BMP).

**언어**를 고릅니다 — **한국어 + 영어**(기본) · **한국어** · **영어** · **일본어**. **텍스트 추출**을 누르면 진행률과 상태가 표시되고, 끝나면 **추출한 텍스트**가 편집 가능한 칸에 나옵니다. 글자를 고치고 **복사**하거나 **TXT 저장**으로 내려받고, **텍스트 비교**나 **마크다운으로 쓰기**로 이어 보낼 수 있습니다.

> **처음 한 번만** 인식 데이터를 기기에 저장합니다. 그 뒤로는 **오프라인에서도** 동작합니다.
> 사진(스캔·캡처)의 글자가 또렷하고 클수록 잘 읽습니다. 기울거나 흐린 사진은 정확도가 떨어집니다.

### 13) 파일 압축 — 이미지와 PDF 용량 줄이기, ZIP 묶기와 풀기

위쪽 **이미지 / PDF / ZIP** 탭에서 고릅니다.

**이미지 압축**
1. **이미지 선택**(여러 장 가능) 또는 끌어다 놓기 — JPG · PNG · WebP · GIF · HEIC
2. 옵션을 고릅니다.
   - **품질** 40~95 (JPG·WebP에 적용)
   - **가로**: 원본 / 2560 / 1920 / 1280 / 800px — 넘는 사진은 비율을 유지한 채 줄입니다
   - **형식**: 원본 유지 / JPG / WebP / PNG
3. **압축하기** → 파일마다 `원본 → 결과 · 68% 감소`처럼 실제 용량이 표시됩니다.
4. **저장**으로 한 장씩, **전체 저장**으로 한 번에 받습니다. 2장 이상이면 `compressed-images.zip`으로 묶입니다.
> 결과가 원본보다 커지는 파일은 **원본을 그대로** 내려받습니다(화면에 "원본 유지" 표시).
> PNG는 품질 대신 **가로 폭**으로 줄입니다. 투명 배경은 PNG에서 유지됩니다.

**PDF 용량 줄이기**
1. **PDF 선택** 또는 끌어다 놓기 (1개)
2. **화질** — 낮음(96dpi) / 보통(144dpi) / 높음(200dpi), **품질** 50~90
3. **PDF 줄이기** → `3페이지 5.6 MB → 631 KB 89% 감소`처럼 페이지 수와 전/후 용량이 나옵니다 → **저장** (`원본이름-compressed.pdf`)
> 페이지를 그림으로 다시 그려 합치기 때문에 **글자를 선택·복사·검색할 수 없습니다**(용량 우선 방식). 스캔·사진 PDF일수록 크게 줄고, 이미 글자로 된 PDF는 잘 줄지 않습니다.
> 암호가 걸린 PDF는 처리할 수 없습니다.

**ZIP 묶기 · 풀기**
- **파일 묶기**: 파일 여러 개를 올리고 이름을 적은 뒤 **ZIP으로 묶기** → `.zip` 저장
- **ZIP 풀기**: `.zip`을 올리면 안의 파일 **이름·용량 목록**이 나옵니다. **저장**은 하나씩, **전체 저장**은 차례로 받습니다. 브라우저가 여러 파일 저장을 막으면 개별 저장을 쓰세요.

### 14) 영상 모자이크 — 영상 속 얼굴과 번호 가리기

1. **영상 선택** 또는 끌어다 놓기 (MP4 · WebM · MOV)
2. 재생/일시정지와 위치 슬라이더로 가릴 장면을 찾습니다.
3. 미리보기 위를 **마우스나 손가락으로 드래그**해 가릴 사각 영역을 만듭니다(여러 개 가능). **실행취소**는 마지막 영역을, **전체 삭제**는 모든 영역을 지웁니다.
4. **모자이크 / 블러**와 **강도**(6~48)를 고릅니다. 강도는 영상 크기에 맞춰 커집니다.
5. **영상 저장** → 처음부터 끝까지 다시 인코딩하며 진행률이 표시되고, 끝나면 미리보기와 `MP4 · 675 KB · 640×360`이 나옵니다 → **저장** (`원본이름-mosaic.mp4`)

> 저장은 **영상 길이만큼 실시간**으로 걸립니다(5초 영상 → 약 5초). **10~30초 짧은 클립**을 권장합니다.
> 소리는 함께 담깁니다(브라우저가 지원할 때). iPhone Safari는 지원되는 형식(MP4/WebM)으로 저장됩니다.
> 아주 긴 영상은 저장 중 탭을 닫지 마세요. 처리는 기기 안에서만 합니다.

### 15) 마크다운 편집기 — 쓰면서 바로 보는 미리보기

1. 왼쪽(모바일은 **편집** 탭)에 마크다운을 씁니다. 오른쪽(모바일은 **미리보기** 탭)에 즉시 그려집니다. 데스크톱에서는 좌우 2단으로 함께 보입니다.
2. 툴바: **B**(굵게) · *I*(기울임) · ~~S~~(취소선) · H1/H2 · 글머리 · 번호 · 체크박스 · 인용 · 코드 · 링크 · 표
3. **표(Table) · 체크박스 · 코드 블록 · 인용문**까지 GitHub 방식(GFM)으로 표시됩니다.
4. **열기**로 `.md`/`.txt`를 열고, **저장 .md** · **.html** · **인쇄**로 내보냅니다.
5. 쓰는 동안 **자동 임시 저장**되어, 브라우저를 닫았다 열어도 이어서 쓸 수 있습니다(이 기기에만 저장).

> 붙여 넣은 HTML은 **안전한 태그만 남기고 지웁니다**(스크립트·이벤트 속성 제거). 미리보기의 체크박스는 눌러도 문서 내용이 바뀌지 않습니다.
> `.html`로 저장하면 표·코드 스타일이 들어간 독립 문서가 됩니다.

### 16) 단위 변환기 — 길이, 무게, 속도, 온도, 넓이, 부피, 데이터

1. 위쪽에서 종류(**길이·무게·속도·온도·넓이·부피·데이터**)를 고릅니다.
2. 값을 입력하면 같은 종류의 **모든 단위로 바꾼 결과**가 바로 나옵니다.
3. 각 줄의 **기준**을 누르면 그 단위가 기준이 되고(값은 같은 물리량으로 환산), **값이나 복사 아이콘**을 누르면 클립보드에 복사합니다.
4. **넓이**에는 **평**, **무게**에는 **돈·근**, **데이터**에는 SI(KB · MB)와 IEC(KiB · MiB)가 함께 있습니다.

> 100% 오프라인 계산입니다(네트워크를 쓰지 않습니다). 온도는 섭씨·화씨·켈빈을 정확히 환산합니다.

### 17) 환율 계산기 — 12개 통화

1. **금액**을 넣고 기준 통화와 바꿀 통화를 고릅니다(기본 KRW → USD). `⇅`로 맞바꿉니다.
2. 아래 **한눈에 비교**에서 12개 통화(KRW · USD · JPY · EUR · CNY · GBP · VND · THB · TWD · AUD · CAD · SGD)로 바꾼 금액을 함께 봅니다. 줄을 누르면 그 통화가 결과 통화가 됩니다.
3. **환율 갱신**을 누르면 공개 환율표를 받아 **기준 시각과 함께 기기에 저장**합니다. 처음 열 때 저장된 환율이 없으면 온라인일 때 한 번 자동으로 받습니다.
4. 오프라인이거나 갱신에 실패하면 **마지막으로 받은 환율**로 계산하고, 한 번도 받은 적이 없으면 **내장 참고 환율**(“기준일 미갱신”)로 계산합니다.
5. **수동 환율** 칸에 `1 USD = 1350 KRW`처럼 직접 넣고 **적용**하면 그 환율로 계산합니다. **자동 환율로**를 누르면 되돌아갑니다.

> 환율 갱신 때 공개 API(**open.er-api.com**, 실패 시 **frankfurter.app**)에서 **환율표만** 받습니다. **입력한 금액은 어디로도 전송하지 않습니다.**
> 환율은 참고용이며 카드·은행의 실제 결제 환율(수수료 포함)과 다릅니다.

### 18) 클립보드 히스토리 `Mac` — 복사한 텍스트와 이미지 최대 100개

복사할 때마다 텍스트와 이미지를 자동으로 모아 두고, 필요할 때 다시 꺼내 씁니다.

1. Mac 앱을 켜 두면 **복사할 때마다** 자동으로 기록됩니다(0.9초 간격 감시, 바로 앞 항목과 같은 내용은 한 번만).
2. 홈에서 **클립보드 히스토리**를 엽니다. 제목 옆 동그란 **`Mac`** 배지는 Mac 앱 전용 기능이라는 표시입니다.
3. **검색** 칸에 내용 일부를 넣으면 바로 걸러집니다. **전체 · 텍스트 · 이미지 · 고정** 으로 종류를 좁힐 수 있습니다.
4. 항목을 **누르면 클립보드로 다시 복사**됩니다. 오른쪽 버튼으로 **고정(📌) · 복사 · 삭제**를 합니다.
5. **고정**한 항목은 100개가 넘어도 지워지지 않고 맨 위에 남습니다. **전체 삭제**는 한 번 더 눌러야 지워집니다.
6. 브라우저(PWA)에서는 보안 정책상 백그라운드 자동 기록이 되지 않습니다. 대신 아래 칸에 **붙여넣기(Cmd/Ctrl+V)** 해서 직접 보관하고, 같은 방식으로 검색·재복사합니다.

- 저장 위치는 **이 Mac 안**(앱 데이터 폴더 `clipboard.json`)입니다. 서버로 보내지 않습니다.
- **비밀번호 앱에서 복사한 항목은 기록하지 않습니다**(기본 켜짐, ⚙ → 모듈 → 클립보드 히스토리). 1Password·Apple 암호·Bitwarden 같은 앱이 붙이는 숨김 표시(`org.nspasteboard.ConcealedType` 등)가 있으면 그 값은 읽지도 않고 지나갑니다.
- 8MB가 넘는 이미지는 보관하지 않습니다.
- 메모리·디스크를 아끼려고 **최근 100개**만 남깁니다(고정 항목 제외).

### 19) 주소 검색 — 한국(한글, 영문, 우편번호)과 해외

**한국 주소** 탭에서 **주소 검색 열기** 를 누르면 우편번호 검색창이 열립니다(다음·카카오 우편번호 서비스, API 키 필요 없음). 웹(PWA)은 화면 안에, **Mac 앱은 별도 창**으로 뜹니다 — 그 창은 TIP 의 다른 기능을 부를 권한이 없는 격리된 창이라, 우편번호 서비스 스크립트가 앱 데이터에 손댈 수 없습니다.

1. 도로명·건물명·지번으로 찾습니다(예: `테헤란로 1`, `역삼동 1-1`).
2. 목록에서 주소를 고르면 **도로명 주소 · 지번 주소 · 영문 주소 · 우편번호(5자리)** 가 한 번에 나옵니다(건물명이 있으면 함께).
3. 각 줄 오른쪽 **복사** 버튼으로 하나씩, **전체 복사** 로 세 줄을 한 번에 복사합니다.

**해외 주소** 탭은 OpenStreetMap 검색을 씁니다.

1. 도시·거리·건물 이름을 **한글 또는 English** 로 넣고 **검색**(또는 Enter).
2. 결과마다 주소(현지어) · **영문명** · **좌표** 를 복사하거나 **지도 열기** 로 OpenStreetMap 지도를 엽니다.
3. 한 번에 한 번씩만 조회합니다(연속 자동 검색 없음). 결과가 없으면 철자를 바꿔 다시 찾아보세요.

> 이 모듈만 **인터넷이 필요합니다.** 검색어는 **다음(카카오)** 또는 **OpenStreetMap** 으로만 전송되고, TIP 서버(없음)나 다른 곳으로는 가지 않습니다.
> 오프라인이거나 서비스에 연결하지 못하면 화면에 **"인터넷 연결이 필요합니다"** 안내가 뜹니다.

### 20) 배송 조회 — 송장번호 보관과 네이버 배송 조회

택배사·송장번호·별명(예: `시우 기저귀`)을 저장해 두고, 누르면 **네이버 배송조회** 화면을 바로 엽니다. API 키도, 서버도 쓰지 않습니다.

1. **택배사**(CJ대한통운 · 우체국택배 · 한진택배 · 롯데택배 · 로젠택배 · 쿠팡로켓배송 · GS25/CU편의점택배)를 고르고 **송장번호**를 넣습니다. 목록에 없는 택배사는 **직접 입력** 을 골라 이름을 적습니다(예: 경동택배).
2. **별명**은 선택입니다. 넣어 두면 목록에서 `시우 기저귀` 처럼 알아보기 쉽습니다.
3. **저장하고 조회** 를 누르면 목록에 쌓이면서 바로 열립니다.
   - **Mac 앱**: 앱 안의 작은 창(480×720)에서 네이버 배송조회가 열립니다.
   - **웹(PWA)**: 새 탭에서 같은 화면이 열립니다.
4. 목록에서 **조회** 로 다시 열고, **복사** 로 송장번호만 복사하고, **삭제**(한 번 더 눌러 확인)로 지웁니다.
5. 같은 택배사에 같은 송장번호를 다시 넣으면 중복으로 쌓지 않고 그 항목을 위로 올려 다시 조회합니다. 최근에 조회한 항목이 맨 위에 옵니다.

- 저장 위치는 **이 기기**(`localStorage`)이고 최대 **100개** 입니다. 서버로 보내지 않습니다.
- 배송 정보는 **네이버가 보여 주는 화면을 그대로** 씁니다. 그래서 네이버가 바뀌어도 앱은 깨지지 않습니다.
- 조회할 때 **택배사·송장번호가 네이버로 전달**됩니다(조회를 누른 그 순간에만).

### 21) 스티커 메모 `Mac` — 바탕화면에 붙여 두는 메모

Windows 스티커 노트처럼 창 하나가 메모 하나입니다. 홈의 **스티커 메모** 카드, 메뉴 막대의 **새 스티커 메모**, 또는 전역 검색의 `새 스티커`로 띄우고, 단축키는 **설정 → 모듈 → 스티커 메모**에서 정합니다.

- 창 위쪽 막대를 끌어 옮기고, 가장자리로 크기를 바꿉니다(위치·크기 자동 저장).
- 위쪽 버튼: **+** 새 스티커 · **색 동그라미** 색 바꾸기(노랑·딥그린·파랑·분홍·보라·다크) · **핀** 항상 위 · **×** 닫기(내용 유지) · 휴지통 삭제.
- 글자는 입력하고 0.4초 뒤 자동 저장되고, **앱을 다시 켜면 열려 있던 스티커가 그 자리·크기 그대로** 돌아옵니다.
- 저장 위치는 앱 데이터 폴더의 `sticky-notes.json` 하나뿐이며, 어디로도 전송하지 않습니다.

### 22) 화면 스포이드 `Mac` — 화면의 색을 집기

**화면에서 색 고르기**를 누르고 화면의 원하는 점을 클릭하면 그 색이 **설정한 형식(기본 HEX)** 으로 복사됩니다(ESC 로 취소). 최근 색 12개를 기억하고, 누르면 다시 복사합니다. **색상 · 대비 체크로 보내기**를 누르면 그 색이 대비 검사기의 글자색으로 들어갑니다. 색 형식은 **설정 → 모듈 → 화면 스포이드**에서 HEX·RGB·HSL 중에, 자동 복사 여부도 함께 정합니다. 단축키를 걸어 두면 어디서든 한 번에 집습니다.

### 23) 스크린샷 표시 `Mac` — 찍고 바로 화살표와 모자이크

**화면 영역 드래그해서 찍기**로 화면의 한 영역을 찍습니다(처음 한 번은 **화면 기록** 권한). 찍은 그림 위에 **화살표 · 사각형 · 글자 · 모자이크**를 그리고, 색과 굵기를 고를 수 있습니다. **되돌리기**로 마지막 표시를 지우고, **복사** 또는 **저장**(PNG)으로 내보냅니다. 모자이크는 사진 모자이크와 같은 계산을 씁니다.

### 24) 창 분할 `Mac` — 앞 창을 반쪽이나 가운데로

옮길 창을 클릭해 앞으로 가져온 뒤, **왼쪽 절반 · 오른쪽 절반 · 위쪽 절반 · 아래쪽 절반 · 최대화 · 가운데 70%** 중 하나를 누릅니다. 처음에는 macOS **손쉬운 사용** 권한이 필요하다고 안내하며, **손쉬운 사용 설정 열기**로 시스템 설정의 해당 항목이 바로 열립니다. **설정 → 모듈 → 창 분할**에서 명령마다 단축키를 정하거나 **권장 단축키 채우기(⌃⌥ + 방향키)** 로 한 번에 넣을 수 있습니다.

### 25) 파일 이름 일괄 변경 — 찾아 바꾸기, 일련번호, ZIP

여러 파일을 고르거나 화면으로 끌어다 놓고, **찾기/바꾸기(정규식 지원) · 앞에 붙이기 · 뒤에 붙이기 · 일련번호 · 대소문자**를 정하면 아래 **미리 보기**에서 바뀔 이름을 먼저 확인합니다. 이름이 겹치거나 비면 빨갛게 알려 주고 실행을 막습니다.

- **Mac 앱**: Finder 에서 끌어다 놓은 파일은 **디스크의 이름이 실제로 바뀝니다**(같은 폴더 안에서만, 겹치지 않을 때만).
- **웹(PWA)**: 원본은 그대로 두고 **이름을 바꾼 사본을 ZIP** 으로 묶어 내려받습니다.

### 26) 스니펫 — 자주 쓰는 문구 한 번에 복사

이름·별칭(`/mail`)·내용을 저장해 두고, 목록에서 누르면 복사됩니다. **전역 검색**에서 `/mail` 이나 낱말로 찾아 **Enter 한 번**으로 복사할 수 있습니다(설정 → 검색 → 스니펫). 값은 이 기기의 저장소에만 있습니다.

### 27) 타이머 — 분과 초를 정해 세기, 노치 알약에 남은 시간

macOS 기본 시계 앱은 다른 앱이 조종할 API 가 없어 TIP 이 직접 만든 타이머입니다. **분·초를 자유롭게** 넣거나 **1·3·5·10·25분** 프리셋으로 시작하고, **일시정지·재개·+1분·초기화**합니다. 상태는 **노치 알약·노치 패널·메인 창·전역 검색이 하나로 공유**해서, 어디서 시작하든 다른 곳이 같은 남은 시간을 보여 줍니다. 끝나면 Mac 은 **알림 센터 알림 + 소리**, 웹은 **브라우저 알림 + 소리**로 알립니다. 전역 검색(⌥ Space)에서 **`타이머 7분`**, **`타이머 1분 30초`**, **`timer 90s`**, **`타이머 7:30`** 처럼 치면 Enter 한 번으로 바로 시작합니다.

### 28) 글자 수 세기 — 공백 포함·제외, 바이트, 원고지

글을 붙여 넣으면 바로 셉니다. **공백 포함 · 공백 제외 · 단어 · 줄 · UTF-8 바이트 · EUC-KR 바이트 · 원고지(200자) 매수**를 한 표에 보여 주고, **목표 글자 수**를 정하면 남은 수와 진행 막대가 나옵니다. 글자 수는 `Intl.Segmenter` 의 문자 기준이라 이모지도 한 글자로 셉니다.

### 29) 날짜 계산기 — D-day, 더하기, 만 나이, 근무일

**D-day**(오늘 기준 D±N), **날짜 더하기**(일·주·개월, 그 달에 없는 날은 말일로 맞춤), **만 나이**(연 나이·다음 생일), **근무일**(주말과 2024~2027년 법정 공휴일·대체공휴일 제외)을 한 화면에서 셉니다. 근무일 화면에는 어느 해까지 반영했는지 늘 적어 둡니다(임시공휴일은 넣지 않았습니다).

### 30) 한영 타자 변환 — 한글 ↔ 영문 글쇠

**한글 → 영문**(안녕하세요 → dkssudgktpdy)과 **영문 → 한글**(dkssudgktpdy → 안녕하세요)을 두벌식 기준으로 바꿉니다. 겹받침(ㄳ·ㄶ·ㅄ)과 이중모음(ㅘ·ㅙ·ㅢ)도 양쪽으로 처리합니다. 클립보드 히스토리의 **한/영** 버튼은 복사한 글을 알맞은 쪽으로 바꿔 바로 복사합니다.

### 31) 제비뽑기 — 봉투를 한 장씩, 또는 한꺼번에

사람 수(2~12명)와 꽝 개수를 정하면 참가자마다 **캐릭터 아바타**(토끼·고양이·강아지·곰·여우·판다·오리·개구리·병아리·펭귄·코알라·다람쥐 열둘)가 붙은 봉투가 깔립니다. 봉투를 누르면 3D로 뒤집히고 **당첨·꽝 도장이 쾅 찍히며**, 당첨이면 카드 위로 스파클과 컨페티가 터집니다. 봉투는 손을 올리면 살짝 흔들리고, **[모두 열기]** 로 남은 봉투를 한꺼번에 열 수 있습니다. 위쪽에는 **남은 봉투 · 당첨 · 꽝** 수가 실시간으로 표시되고, 이름을 비워 두면 1번부터 자동으로 채워 바로 시작할 수 있습니다. 결과가 모두 나오면 당첨과 꽝을 나눠 보여 주고, **[다시하기]** 는 같은 인원·이름·꽝으로 새로 뽑고 **[새로 설정하기]** 는 인원과 이름을 고치는 화면으로 돌아갑니다.

### 32) 사다리타기 — 캐릭터가 사다리를 타고 내려간다

가로대는 이웃한 기둥마다 **최소 두 개**가 들어가고 어느 칸도 곧장 내려가지 않게 매번 새로 긋습니다(공정한 난수). 둥근 나무 레일 위쪽에는 참가자 **캐릭터 배지**가 앉아 있고, **이름을 누르면** 그 캐릭터가 좌우로 살짝 기울며 내려가며 지나간 길이 색 궤적으로 남습니다. 골인 지점에서는 당첨이면 왕관과 함께 컨페티가 터지고, 꽝이면 울상이 됩니다. **[전체 동시에 보기]** 는 모두 함께 내려가고, **[결과 공개/가리기]** 로 밑의 당첨·꽝을 감췄다가 다시 볼 수 있습니다.

### 33) 선착순 골인 — 네 가지 맵에서 먼저 들어오기

사람 수와 꽝 개수를 정하고 맵을 고르면 셋을 세고 출발합니다. 동그라미 대신 **캐릭터가 머리 위 이름표를 달고** 달리고, 이동 궤적·먼지·충돌 스파크가 따라붙습니다.

- **질주 트랙** — 잔디와 레인 위를 달리며 파란 **부스터 패드**(불꽃 가속), **진흙·바나나**(감속과 표정 변화), **순풍·역풍 게이트**를 지나고, 1등이 **결승 테이프**를 끊습니다.
- **장애물 서킷** — 굽이진 레인에서 **허들**(점프와 감속), **가속 레인**, **여닫는 게이트**가 순위를 흔듭니다.
- **핀볼 드롭** — **튕기는 범퍼**(반짝임과 파동 링), **회전하는 풍차 막대**, **깔때기 가이드**가 있는 물리 보드입니다.
- **지그재그 레일** — 좌우로 감기는 레일과 **왕복 발판**, **가속 슈트**를 타고 내려갑니다.

먼저 들어온 사람이 당첨, 꽝 개수만큼 늦게 들어온 사람이 꽝입니다. 아래에는 **실시간 순위**가, 화면 위에는 도착 알림이 뜨고, **[1x/2x]** 로 속도를 바꿀 수 있습니다. 끝나면 **1·2·3등 시상대**와 전체 순위표, 컨페티가 나옵니다.

세 게임 모두 오른쪽 위 **소리 단추**로 효과음(클릭·뒤집기·범퍼·부스터·도착 팡파레·꽝)을 끄고 켤 수 있고, 이 설정은 기기에 남습니다.

## 4. 프라이버시

- 모든 변환·편집은 **브라우저 안에서** 실행됩니다. 파일을 서버로 올리지 않고, 계정도 필요 없습니다.
- 저장한 결과 파일은 기기의 **다운로드 폴더**(iPhone은 파일 앱의 다운로드)에 저장됩니다.
- 네트워크는 최초 로딩과 업데이트 확인에만 쓰입니다. 한 번 열면 오프라인에서도 동작합니다.
- **환율 계산기**만 예외적으로 네트워크를 씁니다. **환율 갱신**을 누를 때(저장된 환율이 없으면 처음 한 번) 공개 환율 API에서 **환율표만** 받아 기기에 저장하며, **입력한 금액은 전송하지 않습니다**.
- **주소 검색**만 예외적으로 외부 서비스를 씁니다. 한국 주소는 **다음(카카오) 우편번호 서비스**(`t1.kakaocdn.net`)에서 스크립트를 받아 검색하고, 해외 주소는 **OpenStreetMap Nominatim**(`nominatim.openstreetmap.org`)에 검색어를 보냅니다. **검색어만** 가며 파일·다른 정보는 보내지 않습니다.
- **배송 조회**는 조회를 누를 때 **택배사·송장번호를 네이버 배송조회**로 보냅니다(네이버 화면을 앱 안 창·새 탭으로 여는 방식). 저장한 송장 목록 자체는 기기 밖으로 나가지 않습니다.
- **이미지 텍스트 추출(OCR)** 은 인식 엔진과 언어 데이터를 이 앱의 서버(GitHub Pages)에서 **처음 한 번만** 받아 기기에 저장합니다. 그 뒤에는 오프라인에서도 돌고, **이미지는 어디로도 전송되지 않습니다**.
- **스티커 메모**는 앱 데이터 폴더의 `sticky-notes.json` 에만, **스니펫·단축키·기능 설정**은 이 기기의 저장소에만 저장됩니다. 서버가 없으므로 어디로도 나가지 않습니다.
- **화면 스포이드**는 macOS 의 색 샘플러가 돌려준 색 값만 받고, **화면 글자 읽기**는 사용자가 드래그한 영역만 임시 폴더에 잠깐 저장해 OCR 모듈에 넘깁니다(다른 화면은 찍지 않습니다). 둘 다 **화면 기록** 권한이 필요할 수 있으며, **창 분할**은 창의 위치·크기만 바꾸고 내용은 읽지 않습니다(**손쉬운 사용** 권한).
- **문의하기**(⚙ → 일반 → 데이터와 문의)는 기본 메일 앱으로 `appfle.io@gmail.com` 앞 편지를 엽니다 — TIP 이 내용을 대신 보내지 않습니다.

## 5. 알려진 제한사항

- **iOS Safari**: WebP **저장** 미지원 → PNG로 대체, HEIC는 내장 디코더 사용(느릴 수 있음), 동영상 클립 자르기는 기기·버전에 따라 제한될 수 있어 GIF를 권장합니다.
- **동영상**: 브라우저가 지원하지 않는 코덱은 재생되지 않습니다. 클립 저장은 구간 길이만큼 실시간이 걸립니다.
- **PDF**: 암호가 걸린 PDF는 결과가 비어 있을 수 있습니다.
- **사진**: 긴 변 3200px를 넘는 사진은 축소해서 편집합니다.
- **OCR**: 첫 실행 때 인식 데이터(약 3~4MB)를 받는 동안 잠깐 기다려야 합니다. 화면이 기울거나 글자가 작으면 정확도가 떨어집니다.
- **스포이드**: Chrome·Edge 등 일부 브라우저에만 있습니다.
- **정규식**: 자바스크립트 문법 기준입니다(PHP·Python의 정규식과 일부 다릅니다).
- **파일 압축(이미지)**: 이미 작게 최적화된 PNG는 다시 압축하면 커질 수 있어 원본을 그대로 내려받습니다.
- **파일 압축(PDF)**: 용량을 줄이는 대신 **글자 선택·검색이 안 됩니다**(페이지를 그림으로 다시 그림). 암호 PDF는 안 됩니다.
- **영상 모자이크**: 저장에 영상 길이만큼 걸립니다. 아주 긴 영상·고해상도 영상은 나눠서 처리하세요. 브라우저가 MediaRecorder를 지원해야 합니다.
- **마크다운 편집기**: 초안은 이 브라우저에만 저장됩니다(다른 기기와 공유되지 않음). 붙여 넣은 HTML은 안전한 태그만 남깁니다.
- **환율**: 참고용 환율이며 실제 결제 환율과 다릅니다. 한 번도 갱신하지 않았으면 기기에 들어 있는 참고값으로 계산합니다.
- **홈 카드 순서**: 같은 묶음 안에서만 바꿀 수 있습니다. 모듈을 **고정**하면 순서와 상관없이 맨 위 **고정됨**으로 올라가고, 고정을 풀면 원래 묶음의 저장된 자리로 돌아갑니다. 순서는 **이 기기의 브라우저에만** 저장됩니다(다른 기기와 공유되지 않음).
- **Mac 앱 첫 실행**: 정식 Developer ID 서명·공증이 붙기 전 빌드는 macOS가 한 번 막습니다. Finder에서 **우클릭 → 열기** 를 쓰거나, 터미널에서 `xattr -dr com.apple.quarantine /Applications/TIP.app` 을 실행하면 됩니다.
- **Mac 앱 노치 반원**: 반원(간단히 보기)과 전체 보기의 켜 둔 모듈 줄에는 한 번에 **7칸**만 보입니다. 그보다 많이 켜 두면 휠·화살표로 돌려서 넘깁니다. 컴팩트 창에서 연 파일은 그 창에서만 유지되고, 창을 닫으면 사라집니다. 판은 위쪽이 화면 맨 위에 붙은 일직선, 아래쪽이 납작한 반타원입니다(폭 640px · 높이 252px, 노치가 있는 Mac 은 노치 높이만큼 더 깁니다). 배경 불투명도는 ⚙️ → 노치 → **반원 배경 불투명도**(70~100%, 기본 92%)에서 바꿉니다. 노치를 키보드 단축키로 여는 기능은 아직 없습니다(메뉴 막대 아이콘이나 알약을 눌러 엽니다).
- **앱 업데이트**: Mac 앱은 GitHub Releases 의 **공개 최신 버전**만 읽어 새 버전을 확인합니다(사용자 데이터는 보내지 않습니다 — 앱이 밖으로 접속하는 유일한 곳입니다). 자동 설치는 `/Applications` 에 쓸 수 있어야 하고, 실패하면 이전 버전으로 되돌린 뒤 사유를 보여 줍니다. 새 버전을 자동으로 받을 수 있으려면 그 버전의 Release 에 **`.app.tar.gz` 파일**이 올려져 있어야 합니다.
- **캘린더 달력**: macOS 앱 전용이고 **캘린더 권한**이 필요합니다. 달력 보기(일·주·월)는 한 번에 400일까지만 읽습니다. 표시할 캘린더 선택은 TIP 안에만 저장되어(`tip.calendar.selectedIds.v1`) **맥 캘린더 앱의 체크 상태를 바꾸지 않습니다**. 일정은 60초 캐시합니다.
- **주소 검색**: 인터넷이 필요합니다(이 모듈만 외부 서비스 사용). 다음 우편번호 서비스는 **한국 주소만** 되고, 해외 주소는 OpenStreetMap 데이터라 **건물 호수 단위 정확도**는 지역에 따라 다릅니다. 영문 주소는 도로명 기준이며, 오래된 지번은 영문 표기가 없을 수 있습니다.
- **배송 조회**: 인터넷과 네이버 접속이 필요합니다. 네이버 **모바일 판**(`m.search.naver.com`)을 열며, Mac 앱 창은 아이폰 Safari 로 인식되어 **460×740** 크기에 한 열로 맞춰 나옵니다(v1.13.0). 앱 안 창은 **Mac 앱에서만** 열리고 웹은 새 탭으로 열립니다(브라우저 팝업을 막아 두면 새 탭이 열리지 않으니 이 사이트의 팝업을 허용해 주세요). 네이버가 배송 정보를 제공하지 않는 택배사·송장번호는 네이버 화면에서 직접 확인해야 합니다.
- **클립보드 히스토리**: Mac 앱에서만 자동 기록됩니다. 브라우저는 붙여넣기로 직접 보관합니다. 최근 100개만 남고, 8MB가 넘는 이미지는 건너뜁니다.
- **노치 아일랜드**: macOS 앱 전용입니다. 노치가 없는 모니터에서도 창은 화면 최상단 가운데(메뉴 막대 위)에 붙습니다. 미디어 정보는 **Apple Music·Spotify**만 읽고(다른 플레이어는 표시되지 않음), 처음에는 macOS가 **음악 앱·캘린더 접근 허용**을 물을 수 있습니다(거부하면 해당 위젯이 **권한 필요 안내와 `권한 설정` 버튼**으로 바뀝니다 — 환경설정의 **`macOS 권한 설정`** 그룹에서도 열 수 있습니다). 웹캠 거울은 **카메라 권한**이 필요합니다. 미디어·캘린더는 켠 위젯만 조회하고, 조회가 늦어도 화면은 멈추지 않으며 2초(캘린더 6초) 안에 응답이 없으면 그 위젯만 안내 문구로 바뀝니다. 일정은 5분 캐시합니다.
- **빠른 실행 검색**: macOS 앱 전용 전역 단축키입니다. 다른 앱이 같은 조합을 쓰면 등록되지 않으니 **⚙️ → 빠른 실행 검색 → 변경**에서 다른 조합을 고르세요.
- **Mac 앱 기능 범위**: 앱은 macOS 웹뷰(WKWebView)에서 웹과 같은 화면을 씁니다. 대부분 그대로 동작하지만 OCR(인식 데이터 다운로드)·영상 모자이크(녹화)처럼 워커·wasm을 쓰는 기능은 실기 검증 전입니다. 문제가 있으면 웹(브라우저)에서 쓰시면 됩니다.
- **업데이트**: 웹은 새 버전이 배포되면 **한 번 새로고침**해야 반영됩니다(오프라인 캐시 구조). Mac 앱은 **⚙️ → 앱 업데이트 → 업데이트 확인** 으로 바로 받을 수 있습니다.
