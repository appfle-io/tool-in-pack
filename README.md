# TIP — TOOL-IN-PACK

**작은 도구들을 한곳에 모은 오프라인 유틸리티 앱.**
PDF·이미지·PDF 병합·모자이크·QR·동영상 GIF부터 JSON·정규식·색 대비·앱 아이콘·이미지 글자 추출(OCR)까지,
파일을 서버로 보내지 않고 브라우저(기기) 안에서만 처리합니다.

- **라이브**: <https://appfle-io.github.io/tool-in-pack/>
- 설치 없이 웹으로 열고, 홈 화면에 추가하면 앱처럼 전체 화면으로 쓸 수 있습니다.
- 한 번 열어 두면 **인터넷 없이도** 동작합니다(오프라인 캐시).

## 1. 시작하기

### iPhone / iPad (Safari)

1. Safari에서 <https://appfle-io.github.io/tool-in-pack/> 를 엽니다.
2. 하단 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면의 **TIP** 아이콘으로 실행하면 주소창 없이 전체 화면으로 뜹니다.

### 데스크톱 / Mac

1. Chrome · Edge · Arc · Safari 에서 위 주소를 엽니다.
2. 주소창 오른쪽의 **설치** 아이콘(또는 메뉴 → 앱 설치 / 홈 화면에 추가)으로 설치하면 독·Dock에서 바로 실행됩니다.
3. 넓은 화면에서는 두 칸 레이아웃으로 바뀌고, 파일을 **끌어다 놓기**로 바로 열 수 있습니다.

### 홈 화면(모듈 목록)

모듈은 성격에 따라 **문서 · 미디어 · 유틸리티** 세 묶음으로 나뉘어 있습니다.

- 맨 위 **고정됨**: 핀을 켠 모듈만 모입니다. 하나도 없으면 이 칸은 나타나지 않습니다.
- 그 아래 **문서 → 미디어 → 유틸리티** 순서로 모듈이 놓입니다.
- 묶음 제목 옆 숫자는 그 묶음에 든 모듈 수입니다.
- 카드 왼쪽 영역을 누르거나 **실행** 버튼을 누르면 모듈이 열립니다.
- 오른쪽 **스위치**로 모듈을 켜고 끌 수 있습니다(끈 모듈은 실행되지 않음).
- **핀** 아이콘을 누르면 **고정됨** 칸으로 올라가고, 다시 누르면 원래 묶음으로 돌아갑니다.
- 좁은 화면은 한 줄씩, 넓은 화면(900px 이상)은 묶음마다 두 줄로 보입니다.

## 2. 모듈별 사용법

### 1) 문서 리더 — PDF · HWP · HWPX

- **파일 열기** 버튼을 누르거나 파일을 화면에 끌어다 놓습니다. (PDF · HWP · HWPX)
- **PDF**: 페이지 이동(‹ ›), 확대/축소, 폭 맞춤, 회전. 모바일에서는 두 손가락 핀치로 확대할 수 있습니다.
- **HWP / HWPX**: 문서를 스크롤해 읽습니다. 표·이미지도 함께 표시됩니다.
- 페이지 수가 많은 PDF도 기기 안에서 그때그때 그려서 보여줍니다(파일 업로드 없음).
> 암호가 걸린 문서는 열리지 않을 수 있습니다. 암호를 푼 파일로 다시 시도해 주세요.

### 2) 이미지 컨버터 — 이미지 포맷 변환 · 리사이즈

- **이미지 선택**(여러 장 동시 선택 가능) 또는 끌어다 놓기.
- **입력**: JPG · PNG · WebP · GIF · BMP · SVG · AVIF · ICO · HEIC/HEIF
- **출력**: PNG · JPG · WebP · ICO · BMP · PDF
- 옵션: **품질**(JPG/WebP), **너비**(px, 비율 유지) — 비워 두면 원본 크기.
- **변환** 후 파일별 `원본 → 결과` 용량과 증감률을 보여 줍니다. **저장** 또는 **전체 저장**으로 내려받습니다.
- 여러 장을 한 번에 변환할 때 파일명이 겹치면 `-2`, `-3`이 붙습니다.
> HEIC는 브라우저가 직접 못 읽으면 내장 디코더로 변환합니다. 아주 큰 HEIC는 시간이 조금 걸릴 수 있습니다.
> iPhone Safari는 WebP **저장**을 지원하지 않아 PNG로 대체되는 경우가 있습니다(화면에 안내 표시).

### 3) PDF 합치기 · 페이지 추출

상단에서 **합치기 / 페이지 추출** 두 가지 모드를 고릅니다.

**합치기**
1. **PDF 선택**으로 2개 이상 올립니다(끌어다 놓기 가능). 파일마다 페이지 수와 용량이 표시됩니다.
2. 행 오른쪽 **∧ ∨** 로 순서를 바꾸고, **✕** 로 목록에서 뺍니다.
3. **합치기** → 결과 카드에 `전체 페이지 수 · 용량`이 나오면 **저장**.

**페이지 추출**
1. PDF 1개를 올리면 **총 페이지 수**가 표시됩니다.
2. **범위** 칸에 `1, 3-5` 처럼 입력하거나, 아래 **페이지 번호 칩**을 눌러 고릅니다. (칩과 입력은 서로 맞춰 바뀝니다)
3. **선택 페이지 추출** → `n페이지` 결과를 **저장**.

> 범위 표기: `3` (한 장), `2-6` (구간), `1, 4, 7-9` (섞어 쓰기). 문서 범위를 벗어난 번호는 무시됩니다.
> 암호가 걸린 PDF는 결과가 빈 페이지로 나올 수 있습니다.

### 4) 모자이크 · EXIF 위치정보 제거

사진을 올리면 **먼저 사진에 들어 있는 정보를 보여 줍니다** — 촬영 기기, 촬영 일시, 조리개·ISO·렌즈, 그리고 **GPS 위도·경도**(있으면 붉게 표시). 정보가 없으면 "EXIF / 위치정보 없음"이라고 나옵니다.

1. **사진 선택** 또는 끌어다 놓기 (JPG · PNG · WebP · HEIC)
2. **가리기 도구**
   - **방식**: 모자이크 / 블러
   - **모양**: 붓(문지르듯 칠하기) / 사각(끌어서 영역 지정)
   - **강도**: 1~10 (모자이크 블록 크기·블러 반경)
   - **붓 크기**: 화면에서 보이는 크기 그대로
   - **실행 취소**로 한 번에 하나씩 되돌리고, **초기화**로 원본으로 돌립니다.
3. **저장**: PNG(무손실) 또는 JPG → 저장하면 **저장한 파일을 다시 검사해서** `저장 전 EXIF n항목 · GPS 포함 → 저장 후 0항목`과 “메타데이터 0건”을 확인해 보여 줍니다.

> 사진을 캔버스로 다시 그려 저장하기 때문에 EXIF·GPS·촬영 정보가 **완전히 사라집니다**. (원본 파일은 그대로 남아 있습니다)
> 사진이 아주 크면 긴 변 3200px로 맞춰 편집합니다.

### 5) QR 생성기 — URL · 텍스트 · 와이파이

1. 위쪽에서 **URL / 텍스트 / 와이파이** 중 하나를 고릅니다.
   - URL: 주소를 입력
   - 텍스트: 여러 줄 문장도 가능
   - 와이파이: **SSID**, **비밀번호**, **암호화**(WPA/WPA2/WPA3 · WEP · 없음) — 손님이 QR만 찍으면 와이파이에 접속됩니다.
2. 입력하는 즉시 **미리보기**가 갱신되고, QR에 담기는 실제 내용도 아래에 표시됩니다.
3. 옵션: **크기**(256 / 512 / 1024px) · **여백**(0~8) · **오류 정정**(L/M/Q/H) · **전경/배경색**(색 바꾸기 버튼 포함)
4. **PNG 저장** 또는 **SVG 저장**(인쇄·확대용).

> 비밀번호에 `;` `,` `:` `"` `\` 가 들어가도 자동으로 이스케이프되어 스캔이 깨지지 않습니다.
> 너무 긴 내용은 QR로 만들 수 없어 안내가 뜹니다.

### 6) 동영상 자르기 · GIF 변환

동영상을 올리면 길이·해상도·용량이 표시되고, 위쪽 플레이어에서 미리 볼 수 있습니다.

- **구간**: 시작/끝 슬라이더로 자를 구간을 정합니다. 아래에 `구간 길이 · GIF 프레임 수`가 나옵니다.
- **GIF 변환**: FPS(5/10/15)와 가로 폭(320/480/640)을 고르고 **GIF 만들기** → 진행률이 표시되고, 완성되면 미리보기와 함께 `프레임 수 · fps · 용량`이 나옵니다 → **저장**.
- **동영상 자르기**: **클립 자르기** → 구간 길이만큼 실시간으로 다시 인코딩한 뒤 `MP4`(Safari) 또는 `WebM`(Chrome/Edge) 클립을 만들어 줍니다. 소리가 있으면 함께 담깁니다 → **저장**.

> **iOS Safari에서는 30초 이내의 짧은 클립**에서 가장 안정적입니다.
> GIF는 최대 300프레임까지 만들 수 있습니다(구간을 줄이거나 FPS를 낮추세요).
> 모든 처리는 기기 안에서 하며, 파일은 어디로도 전송되지 않습니다.


### 7) 개발자 툴팩 — JSON · Base64 · JWT · 시각 · UUID

위쪽 탭으로 도구를 바꿉니다. 다섯 가지 모두 기기 안에서만 계산합니다.

- **JSON**: 입력 칸에 JSON을 붙여 넣고 **정렬 2칸 / 정렬 4칸 / 압축**을 누르면 아래 **결과** 칸에 나옵니다. **검증**은 결과를 바꾸지 않고 `유효한 JSON — 객체 · 키 12개 · 1.2 KB`처럼 종류와 크기만 알려 줍니다. 문법이 틀리면 오류 메시지와 위치(줄·글자)를 보여 줍니다. **결과 복사**로 결과를 클립보드에 담습니다.
- **Base64 · URL**: UTF-8 기준이라 한글·이모지도 깨지지 않습니다. **Base64 인코딩 / 디코딩**, **URL 인코딩 / 디코딩** 네 버튼. **결과를 입력으로**를 누르면 결과가 입력 칸으로 옮겨져 이어서 변환할 수 있습니다.
- **JWT**: 토큰을 붙여 넣으면 **Header · Payload를 자동으로 디코드**해 각각 복사할 수 있게 보여 줍니다. `iat` `nbf` `exp`는 **한국 시간(KST)** 으로 바꿔 표시하고, `exp`는 남은 시간 또는 만료 여부까지 적습니다. **서명(Signature)은 검증하지 않습니다** — 값 확인용입니다.
- **타임스탬프**: Unix 값(10자리 초 / 13자리 밀리초)을 넣고 **변환**하면 **한국 시간 · ISO 8601 · Unix 초 · Unix 밀리초**를 한 번에 보여 줍니다. **현재 시각** 버튼으로 지금 값을 채웁니다. 아래 칸에서 날짜·시각을 고르면 **한국 시간 기준**으로 Unix 초를 계산합니다.
- **UUID**: **1개 / 5개 / 10개 생성** → **UUID v4**가 만들어지고 **복사**로 전체를 복사합니다.

> JSON 오류 위치는 브라우저가 알려 주는 범위 안에서 표시합니다(최신 브라우저는 문제 구간만 알려 주기도 합니다).
> JWT는 디코드만 하므로 서명이 맞는지는 확인할 수 없습니다.

### 8) 텍스트 비교 · 정리 — 줄 단위 diff · 글자수

위 탭에서 **비교**와 **정리 · 통계**를 오갑니다.

- **비교**: **원본**과 **수정본**을 넣으면 입력하는 동안 자동으로 비교합니다. 줄 단위로 **추가(초록 +) / 삭제(빨강 −) / 동일**을 나란히 번호와 함께 보여 주고, 위에 `추가 2줄 · 삭제 1줄 · 동일 3줄` 통계가 나옵니다. **좌우 바꾸기**로 두 칸을 맞바꿉니다.
- **정리 · 통계**: 붙여 넣는 즉시 **글자수(공백 포함·제외) · 단어 수 · 줄 수 · UTF-8 바이트**를 셉니다.
  - **앞뒤 공백 정리**, **빈 줄 제거**, **중복 줄 제거**, **오름차순 정렬**, **내림차순 정렬**, **되돌리기**, **복사**.
  - **되돌리기**는 바로 전 상태로 한 번 돌아갑니다.

> 줄이 1,200줄을 넘는 큰 입력은 계산을 가볍게 하려고 자리 기준으로 비교하며, 그 사실을 화면에 표시합니다.
> 중복 줄 제거는 앞뒤 공백을 무시하고 같은 줄을 하나만 남깁니다.

### 9) 정규식 테스터 — 매치 하이라이트 · 캡처 그룹

1. **패턴** 칸에 정규식을 넣고 오른쪽 **g i m s** 플래그를 켜고 끕니다.
2. **테스트 문자열**에 글을 넣으면 일치하는 부분이 **바로 강조**되고, 아래에 `매치 3개`가 표시됩니다.
3. **매치 목록**에서 각 매치의 값과 위치(`4–20`), **캡처 그룹**(이름이 있으면 이름까지)을 확인합니다.
4. **프리셋 칩**(이메일 · 휴대폰 · URL · IPv4 · 한글만 · 숫자만)을 누르면 패턴이 채워집니다.

> 패턴이 잘못되면(예: `[`) 앱이 멈추지 않고 **문법 오류 메시지**만 보여 줍니다.
> `g`를 끄면 첫 매치만 강조하고, 전체 매치 수는 참고로 함께 알려 줍니다.
> 자바스크립트 정규식 문법을 그대로 씁니다(다른 언어의 정규식과 일부 문법이 다릅니다).

### 10) 색상 · 대비 체크 — HEX · RGB · HSL · WCAG

1. **글자색**과 **배경색**을 색 상자에서 고르거나, **HEX · RGB · HSL** 칸에 직접 입력합니다. 한 칸을 고치면 나머지 두 칸이 즉시 함께 바뀝니다.
   - HEX `#2E5E4E`, RGB `46, 94, 78`, HSL `162, 32%, 27%` 형식.
2. 아래 **대비율**이 `7.43 : 1`처럼 나오고, **일반 텍스트 AA(4.5:1) · AAA(7:1) · 큰 텍스트 AA(3:1)** 통과 여부를 배지로 보여 줍니다.
3. **미리보기**에서 24px 큰 텍스트와 14px 본문이 실제 색으로 어떻게 보이는지 확인합니다.
4. **글자 ↔ 배경** 버튼으로 두 색을 맞바꾸고, 각 칸 옆 **복사**로 값을 복사합니다.

> **스포이드** 버튼은 화면의 색을 집을 수 있는 브라우저(Chrome·Edge 등)에서만 나타납니다. iPhone Safari에는 없습니다.

### 11) 앱 아이콘 생성기 — PNG 7종 + manifest

1. **이미지 선택** 또는 끌어다 놓기 (PNG · JPG · WebP · SVG). 1024px 이상을 권장합니다.
2. **맞춤** 방식 선택
   - **정사각 크롭**: 가운데를 기준으로 꽉 채워 자릅니다(로고가 중앙에 있을 때).
   - **여백 맞춤**: 이미지 전체가 들어가게 하고 남는 곳을 **배경색**으로 채웁니다.
3. **PNG 7종 만들기** → **16 · 32 · 48 · 180 · 192 · 512 · 1024px** 미리보기와 각 파일 용량이 나옵니다. 미리보기를 누르면 그 크기 하나만 저장됩니다.
4. **ZIP 저장** → `app-icons.zip`에 `icons/icon-*.png` 7개와 **`manifest-snippet.json`** 이 함께 담깁니다. ZIP을 프로젝트에 풀고 스니펫을 `manifest.json`의 `icons`에 넣으면 됩니다.

> 1024px보다 작은 원본은 512 · 1024px를 확대하므로 조금 흐려질 수 있습니다.
> 결과는 투명 배경을 살린 PNG입니다(원본이 JPG면 사각형 배경이 그대로 남습니다).

### 12) 이미지 텍스트 추출 — OCR (한국어 · 영어)

1. **이미지 선택** 또는 끌어다 놓기 (PNG · JPG · WebP · BMP).
2. **언어**를 고릅니다 — **한국어 + 영어**(기본) · **한국어** · **영어**.
3. **텍스트 추출**을 누르면 진행률과 상태가 표시되고, 끝나면 **추출한 텍스트**가 편집 가능한 칸에 나옵니다.
4. 글자를 고치고 **복사**하거나 **TXT 저장**(`원본이름-text.txt`)으로 내려받습니다.

> **처음 한 번만** 인식 데이터를 기기에 저장합니다(한국어+영어 약 3MB). 그 뒤로는 **오프라인에서도** 동작합니다.
> 사진(스캔·캡처)의 글자가 또렷하고 클수록 잘 읽습니다. 기울거나 흐린 사진은 정확도가 떨어집니다.
> 언어를 잘못 고르면 다른 문자는 거의 읽지 못합니다(예: 영어만 고르고 한글 사진).

## 4. 프라이버시

- 모든 변환·편집은 **브라우저 안에서** 실행됩니다. 파일을 서버로 올리지 않고, 계정도 필요 없습니다.
- 저장한 결과 파일은 기기의 **다운로드 폴더**(iPhone은 파일 앱의 다운로드)에 저장됩니다.
- 네트워크는 최초 로딩과 업데이트 확인에만 쓰입니다. 한 번 열면 오프라인에서도 동작합니다.
- **이미지 텍스트 추출(OCR)** 은 인식 엔진과 언어 데이터를 이 앱의 서버(GitHub Pages)에서 **처음 한 번만** 받아 기기에 저장합니다. 그 뒤에는 오프라인에서도 돌고, **이미지는 어디로도 전송되지 않습니다**.

## 5. 알려진 제한사항

- **iOS Safari**: WebP **저장** 미지원 → PNG로 대체, HEIC는 내장 디코더 사용(느릴 수 있음), 동영상 클립 자르기는 기기·버전에 따라 제한될 수 있어 GIF를 권장합니다.
- **동영상**: 브라우저가 지원하지 않는 코덱은 재생되지 않습니다. 클립 저장은 구간 길이만큼 실시간이 걸립니다.
- **PDF**: 암호가 걸린 PDF는 결과가 비어 있을 수 있습니다.
- **사진**: 긴 변 3200px를 넘는 사진은 축소해서 편집합니다.
- **OCR**: 첫 실행 때 인식 데이터(약 3~4MB)를 받는 동안 잠깐 기다려야 합니다. 화면이 기울거나 글자가 작으면 정확도가 떨어집니다.
- **스포이드**: Chrome·Edge 등 일부 브라우저에만 있습니다.
- **정규식**: 자바스크립트 문법 기준입니다(PHP·Python의 정규식과 일부 다릅니다).
- **업데이트**: 새 버전이 배포되면 **한 번 새로고침**해야 반영됩니다(오프라인 캐시 구조).
